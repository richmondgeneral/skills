# Gmail Keyboard Shortcuts Reference

## Prerequisites
Keyboard shortcuts must be enabled: Settings (gear icon) → See all settings → General → Keyboard shortcuts → ON

## Compose & Chat

| Shortcut | Action |
|----------|--------|
| `c` | Compose new message |
| `d` | Compose in new tab |
| `Cmd+Enter` | Send message (Mac) |
| `Cmd+Shift+c` | Add Cc recipients |
| `Cmd+Shift+b` | Add Bcc recipients |
| `Cmd+k` | Insert link |

## Navigation

| Shortcut | Action |
|----------|--------|
| `g` then `i` | Go to Inbox |
| `g` then `s` | Go to Starred |
| `g` then `t` | Go to Sent |
| `g` then `d` | Go to Drafts |
| `g` then `a` | Go to All Mail |
| `g` then `b` | Go to Snoozed |
| `g` then `k` | Go to Tasks |
| `g` then `l` | Go to Label (then type label name) |
| `/` | Focus search bar |
| `u` | Back to conversation list |

## Thread Navigation

| Shortcut | Action |
|----------|--------|
| `j` | Move to older conversation |
| `k` | Move to newer conversation |
| `o` or `Enter` | Open conversation |
| `n` | Next message within thread |
| `p` | Previous message within thread |
| `` ` `` | Go to next inbox section |
| `~` | Go to previous inbox section |

## Selection

| Shortcut | Action |
|----------|--------|
| `x` | Select/deselect conversation |
| `* a` | Select all conversations |
| `* n` | Deselect all conversations |
| `* r` | Select all read conversations |
| `* u` | Select all unread conversations |
| `* s` | Select all starred conversations |
| `* t` | Select all unstarred conversations |

## Efficiency Combos

### Fast Delete Loop (in search results)
```
o → # → (auto-advances) → # → # → ...
```

### Fast Archive Loop
```
o → e → (auto-advances) → e → e → ...
```

### Batch Select + Action
```
x → j → x → j → x → ... → # (or e, or v, or l)
```

### Quick Search → Act
```
/ → type query → Return → * a → # (delete all results)
```

### Fast Unsubscribe Loop
```
o → (find Unsubscribe) → click → confirm → # → (repeat)
```

## Two-Key Sequences

Some shortcuts are two-key sequences — press the first key, release, then press the second:

- `g` + `i` = Go to Inbox
- `g` + `s` = Go to Starred  
- `g` + `t` = Go to Sent
- `g` + `d` = Go to Drafts
- `g` + `a` = Go to All Mail
- `* ` + `a` = Select all
- `* ` + `n` = Deselect all
- `* ` + `r` = Select read
- `* ` + `u` = Select unread

When using `computer → key`, send these as separate key presses:
```
computer → key "g"
computer → key "i"
```
