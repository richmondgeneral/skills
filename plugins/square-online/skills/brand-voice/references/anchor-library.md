# Anchor Library

The cultural, historical, and craft anchors used in Richmond General product descriptions. Pull from this list when writing or rewriting items  -  reusing anchors across similar items makes the catalog read as one curated shop instead of independent listings.

## How to use this file

When a `catalog-voice-rewrite` task needs a "middle paragraph" anchor for an item, check this library first. If a comparable item type is here, use its anchor. If the item is genuinely new (no comparable type in the catalog), draft a new anchor and add it to this library so future items follow the same line.

Anchors should be:
- **Specific**  -  name an era, a maker, a tradition, a place
- **Brief**  -  one or two sentences max
- **Confident**  -  assert the connection plainly, don't hedge

## Closing-line library

The fourth paragraph of every description ends with a use scenario. Recurring patterns:

**Domestic scenes**  -  "Plug it in next to a brass lamp and a stack of mystery paperbacks." / "Pairs with hot chocolate and a cleared kitchen table." / "Goes well with leather chairs and lamp light."

**Gift framing**  -  "Good gift, good stocking stuffer." / "Good gift for an aviation kid; pairs with any vintage model plane on a shelf."

**Buyer-as-peer**  -  "For Silver Age collectors and readers who like vintage sci-fi for what it actually is rather than what it should be." / "For Dick Tracy collectors, comic-art researchers, or anyone tracking the institutional history of American cartooning."

**Cross-sells**  -  "Pairs with the watercolor brush set we also stock." / "Pairs with our Wellness & Apothecary sage bundles." / "Companion to our 1926-era reprint."

**Curatorial confidence**  -  "We acquired three; two remain." / "One of two we acquired."

## How to add new anchors

When you encounter an item type not in this library (e.g., the first vintage typewriter, the first hand-knit scarf):

1. Do the research. Don't fake an anchor  -  if you don't know what era a typewriter is from, find out before writing.
2. Identify the cultural/era frame the item lives in.
3. Write the anchor in one or two sentences using the same compact style as the existing entries.
4. Add it to this file under the appropriate category, so the next similar item uses the same anchor.
5. If a category is missing entirely (e.g., textiles, vintage tools, ceramics from a region not yet represented), add a new H3 header.

This file should grow with the catalog. A well-maintained anchor library is what keeps 200 listings from sounding like 200 different shops.
