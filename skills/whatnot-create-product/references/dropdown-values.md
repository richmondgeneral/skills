## DOM Structure Notes

### Form Field Pattern

Each combobox dropdown follows this DOM pattern:

```
button (wrapper)
  textbox [hidden] — stores the selected value ID (base64-encoded or enum)
  combobox [visible] — the text input the user sees
  label — field name
  button — "Open dropdown" toggle
```

The **hidden textbox** is what gets submitted. If it's empty after using `form_input`,
the selection didn't register with React.

### Dropdown Dialog Pattern

Each dropdown's options live in a `dialog > listbox > option` structure that exists
in the DOM even when not visible:

```
dialog
  listbox
    option
      generic "Option Text"
    option
      generic "Option Text"
    ...
```

Use `read_page` with the dialog's ref_id to enumerate all options for any dropdown.

### Pricing Section

```
Format: BUY_IT_NOW | AUCTION (hidden textbox)
Price: currency input
Currency: USD (hidden textbox)
```

Toggle switches for Flash Sale, Accept Offers, Reserve for Live.
